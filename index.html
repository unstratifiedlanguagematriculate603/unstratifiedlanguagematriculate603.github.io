📺 samsung-kiosk - Turn Your TV Into a Kiosk

A simple web app that makes any Samsung Smart TV display a single web page in full-screen kiosk mode. Perfect for digital signage, waiting rooms, retail displays, and more.

✨ Features

  • Full-screen kiosk mode – Locks your TV to a single web page with no distractions.
  • Easy configuration – All settings live in a simple .env file: URL, basic auth, redirect or iframe mode, zoom, and volume.
  • Basic authentication support – Protect your kiosk page with a username and password.
  • Flexible display modes – Choose between redirect mode or iframe mode depending on your content.
  • Adjustable zoom and volume – Fine-tune the viewing experience for any screen size or environment.
  • Packaged and signed .wgt – The included build script creates a signed widget file ready for sideloading onto your Samsung TV.

⚙️ Configuration

samsung-kiosk is configured entirely through a .env file. The following settings are available:

  • URL – The web page you want to display.
  • Basic Auth – Optional username and password for protected pages.
  • Mode – Choose redirect or iframe display.
  • Zoom – Adjust the page zoom level.
  • Volume – Set the default TV volume.

📺 Compatibility

samsung-kiosk works with Samsung Smart TVs that support Tizen. It is ideal for digital signage, kiosk applications, and any scenario where you need a locked-down browser on a Samsung TV.
