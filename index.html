Cage is a simple Windows tool that tracks your LLM usage, shows how much money you save by using agent tools, and compares AI work costs to human worker costs. No coding required. Download, run, and see your numbers in minutes.

Free No Installation Needed Windows 10 / 11

🚀 Getting Started

Follow these three steps to start tracking your AI costs.

  1. Visit the download page. Go to the Cage releases page.
  2. Download the Windows file. Look for the file named Cage_Windows_x64.exe (or similar .exe file). Click it to download.
  3. Run the program. Double-click the downloaded file. Windows might show a security warning – click "Run anyway" (it is safe). The Cage window will open.

That is it. You do not need to install Python or any other software.

💻 System Requirements

  • Operating system: Windows 10 or Windows 11 (64-bit).
  • RAM: 4 GB minimum (8 GB recommended).
